# WeatherApp
WeatherNow is a small frontend experiment I built while learning how APIs and UI interaction work in JavaScript. 
It’s not a fully functional product — more of a trial-and-error project where I explored fetching weather data, managing user input, and displaying it cleanly on screen.
The app currently runs on mock data (instead of a live API key) to keep it simple and fast during testing.

WeatherNow is a simple, fast, and elegant weather app built using HTML, CSS, and JavaScript.
It allows users to instantly check weather conditions by entering any city name — showing temperature, humidity, and overall sky description (like “Clear Sky” or “Cloudy”).
Unlike typical API-dependent apps, this version uses mock weather data to ensure lightning-fast response, even offline — perfect for showcasing front-end logic, UI design, and API integration skills.

💡 Features

🔍 Search any city to view current weather info

🌡️ Displays temperature, humidity, and weather condition

⚡ Instant response (no API delays or key required)

💻 Built with pure HTML, CSS, JavaScript — no frameworks

🎨 Clean and responsive design for all screen sizes

🧠 Tech Stack

Frontend: HTML5, CSS3, JavaScript (ES6)

API Logic: Mock OpenWeather data simulation

Design: Minimal UI with weather card layout
